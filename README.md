# LAPIS26

Material for the lectures "Galactic mergers in our backyard: The Milky Way's interaction with its more massive satellites, the LMC and the SMC", given at the [XII LAPIS 2026 school](https://congresos.unlp.edu.ar/xiilapis2026/).

## Installation

To install the code needed for the projects, follow the steps in the **[installation guide](https://github.com/jngaravitoc/LAPIS26/blob/main/INSTALL.md)**. It explains how to install [Agama](https://github.com/GalacticDynamics-Oxford/Agama), [nbody_streams](https://github.com/appy2806/Nbody_streams) and the other dependencies. Then, in your work environment, run `python check_install.py` to check that everything works.

If you encounter any issues or errors in the installation guide, please don't hesitate to open an [issue](https://github.com/jngaravitoc/LAPIS26/issues) or email me.
